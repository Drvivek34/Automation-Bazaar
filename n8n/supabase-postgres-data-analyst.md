## 📝 What it does
A production-oriented n8n data-analyst agent pattern for querying Supabase or Postgres with shared architecture and security documentation.

## 🎯 Use when
> When a team needs a natural-language data-analysis workflow with explicit security, output, and testing conventions.

## ⚡ Trigger
User question or chat trigger

## 🏁 Steps
1. Import the template and configure the database connection with least privilege.
2. Review row-level security, query guards, PII masking, and cost caps.
3. Test queries against known ground truth and inspect generated SQL.
4. Enable writes or scheduled runs only after an explicit safety review.

## ⚠️ Note
Treat the source repository's security framework as required reading before connecting production data.
