## 📝 What it does
An importable n8n AI-agent chat workflow from the ScraperNode template catalog, intended as a current starting point for conversational agent automations.

## 🎯 Use when
> To bootstrap an n8n agent chat and then replace model, memory, tools, and credentials with your own approved services.

## ⚡ Trigger
Chat or workflow trigger

## 🏁 Steps
1. Import the workflow JSON into n8n.
2. Configure the model, memory, and tool credentials.
3. Test with read-only sample data before enabling writes.
4. Add error handling, cost limits, and authorization checks before production use.
